BURS SİSTEMİ v6

LOCALHOST (bilgisayar / Termux)
  Termux : cd ~/storage/downloads && unzip -o BursSistemi.zip -d ~ && sh ~/BursSistemi/baslat.sh
  Windows: zip'i aç, Baslat.bat'a çift tıkla
  Linux/Mac: sh baslat.sh        Port değiştirmek için: PORT=9090 sh baslat.sh
  Adres: http://localhost:8080
  Güncelleme: yeni zip'i aynı komutla aç (unzip -o). data/ klasörüne (başvurular, belgeler) dokunulmaz.

GITHUB PAGES (sunucusuz demo, veriler tarayıcıda)
  İlk kurulum (repo ana dizini = BursSistemi klasörü):
    git init && git add -A && git commit -m ilk && git branch -M main && git remote add origin https://github.com/KULLANICI/BursSistemi.git && git push -u origin main
    Sonra repo Settings > Pages > Source: GitHub Actions
  Sonraki her güncelleme (tek komut):
    sh github-yukle.sh        (Windows: github-yukle.bat)
  Adres: https://KULLANICI.github.io/BursSistemi/

Demo giriş: yönetici admin / 123 (sabit, değiştirilemez)  |  öğrenci: herhangi 11 haneli TCKN / 123
Giriş logosuna 10 kez basarak Demo Mod ve Normal Mod arasında geçiş yapabilirsiniz (mod seçimi tarayıcıda saklanır).

Öğrenci akışı: Şartlar > Kimlik (ad-soyad, T.C., sınıf, anne, baba) > Belgeler > Başvuru Formu (belgelerden otomatik dolar) > Özet/Gönder
- Başvuru Formu: Word formundaki tüm sorular (kimlik, iletişim, eğitim, ekonomik durum, anne/baba, aile) belgelerden ÖNCE sorulur. Ad yazılırken son kelime soyad sayılır; yalnız ad yazılırsa öğrencinin soyadı kullanılır. Belgeler yüklenince yazdığınız cevapların üzerine yazılmaz.
- Başvuru formu ayrıca yüklenmez.
- Her belgede kişinin adı veya T.C. no görünmeli. e-Devlet belgeleri son 30 gün içinde olmalı. Adli sicil: öğrenci + anne + baba.
- Belgeler toplu seçilebilir; hepsi paralel okunur, sonuç sonda özetlenir.

- e-Devlet ekran görüntülerinde soyad gizli olabilir; belgede kişinin adı (veya T.C. no) görünmesi yeterli. Adı görünmeyen kaydırılmış ekranlar aynı türde tek belge varsa ona eklenir, değilse “Kime ait?” sorulur. Aynı belge iki kez yüklenirse atlanır.
- Demo modunda yüklenen dosyalar tarayıcıda (IndexedDB) saklanır; yönetici panelinde açılır. Aynı tarayıcıdan öğrenci olarak yükleyip admin ile girin.

- Yönetici: başvuru ayrıntısında kullanıcı adı, e-posta ve şifre görünür. Dışa aktarma: Excel (varsayılan), sağdaki oktan CSV. Puanlama ağırlıkları “Şartlar ve Puanlama” sayfasında açılır bölümdedir.
- Demo: alttaki “Belge” sekmesine 10 kez basınca tüm adımlar açılır ve başvuru formuna gidilir; formda “Demo verisiyle doldur” düğmesi vardır.
